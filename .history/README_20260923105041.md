# Pulsar Synth（Pulsar Wang）

基于 **JUCE** 的实验性 **Pulsar / Pulsaret** 合成器插件，实现 Curtis Roads《Microsound》中的 **Pulsar Synthesis** 思想。工程名 `pulsar_synth`，产品名 **「Pulsar Wang」**（v0.0.8），CMake + C++20，macOS（AU / VST3 / Standalone）与 Windows（VST3）双平台。

核心思路：**Train（脉冲列车）** 状态机组织若干 **Pulsar 周期**，每个周期 trigger 一次 **grain 发射**；底层由 **GranularEngine** 以 overlap-add 方式渲染所有活跃 pulsaret（波表帧 × 窗），几乎所有参数都由 **可手绘的包络画布** 沿各自时间线调制。

---

## 声音引擎

### Train 状态机

- **BPM**：插件内部节拍（独立于 DAW），由 **BPM 包络** latch 推进——每走完一个 stage 前进一个包络点。
- **Train Len**：一列 Train 占多少个「拍块」（`trainLenBlock = 60/bpm/beatDivision`）。
- **Train Duty Cycle**：Train 发声段包含多少个 Pulsar 周期。
- **Train Silence**：Train 之间的静音段（以 Pulsar 周期个数计）。

```
pulsarPeriod = trainTime / (trainDutyCycle + trainSilence)
fundamentalFreq = 1 / pulsarPeriod
```

状态机在 `Pulse / IntraSilence / InterTrainSilence` 间切换；参数变更在静音边界切入新 Train，避免硬切。所有 train 相关量在 trigger 时刻存入 **snapshot**，保证一个周期内计算一致。

### Granular 渲染（GranularEngine）

每次 trigger（经过 mask 选通后）spawn 一组 grain，由引擎逐 sample overlap-add：

- **grain 池**：最多 32 个并发 grain，池满时丢弃最旧的。
- **pulsaret 波形**：来自 **多帧波表**（最多 32 帧 × 9600 samples）。可在 Pg Waveform 画布手绘单帧，或一次 load 最多 32 个 wav 文件拼成帧序列；**wavetable scanning** 沿帧序列 ping-pong 扫描、相邻帧线性 morph，**Wave Scan Speed** 控制扫描速率。每帧的 hann 加权 DC 分量在查表时被减去，从源头消除 DC offset。
- **per-grain 窗**：整周期 raised-cosine 窗 × 可调 **grain ADSR** 窗（A/D/R 为寿命占比，S 为电平）。
- **per-grain pan**：等功率声像（√2 补偿，居中 = unity gain）。pan 值在 spawn 时从 **Pan 包络** latch——pulsaret 随包络在声场中扫动，已发声 grain 的尾巴保持原位。
- **per-pulsaret LFO**：AM / FM 两条 LFO 画布以 grain 的 windowPhase 为相位，对每个 pulsaret 内部做幅度 / 音高调制。
- **Duty Cycle Cluster**：一个 trigger 的 grain 扫过多个波形周期（cluster 包络控制），形成脉冲簇 / formant 质感。

### Pulsar Extension

- **Harmonics**：每个 trigger 额外在 3×/5× 基频 spawn 相干谐波层，电平按 1/n 递减，并由独立慢速 Perlin 曲线做「分音呼吸」。
- **Unison Detune**：额外 spawn 一对 ±cents 失谐 grain 拷贝，cents 级失谐产生缓慢拍频（supersaw 式厚度）。
- **元胞自动机 / Perlin 噪声**：活跃 cell 数与 Perlin 调制参与扫描频率与时长的微观变化。

### 节奏 Mask（仅作用于 Train Duty Cycle 段）

| 类型 | 说明 |
|------|------|
| **Off** | 每个 Pulsar 周期都 trigger |
| **Burst Mask** | 用户 0/1 字符串（如 `1011`），按周期索引选通 |
| **Euclid Mask** | 欧几里得节奏 `steps` / `hits` 生成 0/1 序列 |
| **Stochastic Mask** | 随 Train Duty Cycle 长度生成的随机 0/1 序列 |

mask = trigger 门控：被遮蔽的周期不 spawn 新 grain，但绝不打断已发声 grain 的尾巴。

## 调制系统：手绘包络 + 去锁定时间线

所有包络都画在 **EnvelopeCanvas**（9600 点，线性插值查表）上，可 Clear / Random / Load File：

| 包络 | 页面 | 作用 |
|------|------|------|
| **AM Env** | Train Envelope | trigger 时刻 latch 每个 grain 的幅度 |
| **FM Env** | Train Envelope | trigger 时刻 latch 扫描频率偏移 |
| **Pan Env** | Train Envelope | trigger 时刻 latch 每个 grain 的声像（0=左，0.5=中，1=右，Amount 缩放偏离中心的幅度） |
| **Duty Cycle Cluster Env** | Train Envelope | 每个 grain 扫过的波形周期数 |
| **AM LFO / FM LFO** | LFO | 以 grain windowPhase 为相位的 per-pulsaret 内部调制 |
| **BPM Env** | Main | latch 推进的内部 BPM 曲线 |
| **Pg Waveform** | Main | pulsaret 单周期波形（手绘或 load 最多 32 个 wav） |

**时间线去锁定**：amp/fm/pan/cluster 各包络沿黄金比例族的**无理数速率比**（1、1/φ、√(1/φ)、√φ）推进——各条包络的循环周期互不成整数比，组合状态几乎永不重演，声音沿包络持续演化而不是固定 loop。**Envelope Scan Speed** 整体缩放包络时间线速率。

## 信号流（音频线程）

```
processBlock
  → PulsarSynth::renderNextBlock
       → PulsarSynthVoice::processBlockSamples
            → 逐采样 processSample()
                 ├── Train 状态机：Pulse / IntraSilence / InterTrainSilence
                 ├── changeStage → maskGatedSpawn()
                 │     ├── mask 选通（Burst / Euclid / Stochastic）
                 │     ├── 从各包络 latch amp / fm / pan / cluster
                 │     └── spawnGrain：基频 + 谐波层 + unison 对
                 └── GranularEngine::renderSample
                       └── 所有活跃 grain：波表查表 × 窗 × ADSR × AM/FM LFO
                           → per-grain equal-power pan → (L, R)
            → pulseBuffer → clamp + fast tanh 软限幅 × output gain → 主 buffer
```

### 预设与状态

- 参数走 **APVTS**；Mask 文本等走 **ValueTree Property**。
- `getStateInformation` / `setStateInformation` 保存 XML；加载 preset 广播 UI 更新。

## 参数一览（APVTS）

| 参数 | 范围 | 说明 |
|------|------|------|
| Output Gain | -60 ~ +6 dB | 输出电平 |
| Train Period | 1 ~ 16 | Train 长度（拍块数） |
| Train Duty Cycle | 1 ~ 320 | 发声段 Pulsar 周期数 |
| Train Silence | 0 ~ 64 | Train 间静音周期数 |
| Mask Mode | Off / Burst / Euclid / Stochastic | 节奏 mask |
| Euclid Steps / Hits | 1 ~ 16 | 欧几里得节奏 |
| AM / FM Env Amount | 0 ~ 1 | 包络调制量 |
| Pan Amount | 0.1 ~ 1 | pan 包络偏离中心的幅度 |
| Duty Cycle Cluster Amount | 0.5 ~ 1 | cluster 包络调制量 |
| AM / FM LFO Amount | 0 ~ 1 | per-pulsaret LFO 调制量 |
| Attack / Decay / Sustain / Release | 0 ~ 1 | grain ADSR 窗（寿命占比 / 电平） |
| Harmonics | 0 ~ 1 | 谐波 pulsar 层电平（0 = 关闭） |
| Unison Detune | 0 ~ 50 cents | unison 失谐对（0 = 关闭） |
| Wave Scan Speed | 0 ~ 5 | 波表帧扫描速率 |
| Envelope Scan Speed | 0 ~ 15 | 调制包络时间线速率 |

## UI

三个页面（顶部按钮切换）：

- **Main**：Train 结构（Period / Duty Cycle / Silence）、Mask、ADSR、Harmonic / Detune / Wave Scan Speed / Env Scan Speed 旋钮、BPM 包络、Pg Waveform 画布（手绘或 load 最多 32 个 wav 文件）、输出波形显示。
- **LFO**：AM LFO / FM LFO 画布 + Amount。
- **Train Envelope**：AM / FM / Pan / Duty Cycle Cluster 四条包络画布，各带 Min / Max / Scale / Amount。

## 工具（tools/）

### generate_waveforms.py

单周期波形生成器：每个波形 **9600 samples / 96 kHz** wav 头、峰值归一化、首尾平滑，可直接 load 进 Pg Waveform 波表。覆盖 100+ 波形家族、300+ 波形：带限经典波、pulsaret 粒形（gauss/FOF/VOSIM/sinc/expodec…）、FM/相位失真/wavefold、金属非谐、分形混沌、几何曲线、无噪声复杂形态套装等。

```bash
# 每次运行随机抽参生成全新变体（打印 seed 可复现）
python3 tools/generate_waveforms.py [输出目录]

# 复现某一套
python3 tools/generate_waveforms.py --seed 12345

# 固定参数的经典套装
python3 tools/generate_waveforms.py --fixed
```

依赖：`numpy`。另有 `generate_pulsarets.py` 生成 pulsaret 素材。

## 构建

CMake ≥ 3.28，C++20。JUCE 路径可用环境变量 / CMake 变量 `PULSAR_JUCE_DIR` 指定（macOS 默认 `/Applications/JUCE`，Windows 默认 `E:/env/juce-7.0.9600-windows/JUCE`）。

### macOS

```bash
cmake -B build -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
cmake --build build          # AU + VST3 + Standalone
```

### Windows（VS 2022）

```powershell
cmake -B build -G "Visual Studio 17 2022" -A x64 -DPULSAR_JUCE_DIR="E:/env/juce-7.0.9600-windows/JUCE"
cmake --build build --config Release   # VST3
```

- `COPY_PLUGIN_AFTER_BUILD TRUE`：构建后自动复制插件到系统插件目录（权限不足时可关闭该选项，直接取 `build/pulsar_synth_artefacts/` 下产物）。
- 产物：`build/pulsar_synth_artefacts/[Release/]VST3/Pulsar Wang.vst3`、`Standalone/Pulsar Wang.app|.exe`。

## 运行

- **Standalone**：直接打开 `Pulsar Wang` 应用。
- **DAW**：加载 `Pulsar Wang.vst3`（或 macOS AU），插件为合成器（接收 MIDI 事件总线）。
