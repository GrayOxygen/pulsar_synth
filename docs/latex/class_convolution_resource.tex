\doxysubsection{Detailed Description}
All synth and voice share a \doxylink{class_convolution_resource}{Convolution\+Resource} to maintain impulse file data and do some convolution logic When initialized in prepare\+To\+Play, if the sample rate, sample per block, and num channels change, this Synth\+Engine will reinitialize the \doxylink{class_convolution_resource}{Convolution\+Resource} otherwise keep the instance same.
