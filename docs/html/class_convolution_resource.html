Detailed Description

All synth and voice share a ConvolutionResource to maintain impulse file data and do some convolution logic When initialized in prepareToPlay, if the sample rate, sample per block, and num channels change, this SynthEngine will reinitialize the ConvolutionResource otherwise keep the instance same.
